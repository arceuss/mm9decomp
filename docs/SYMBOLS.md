# Symbols

`config/WR9E/symbols.txt` was generated by decomp-toolkit's analysis of the DOL (no map file exists for this game). Names are address based:

- `fn_XXXXXXXX`: function found by control-flow analysis.
- `lbl_XXXXXXXX`: data object; size and `data:` type were guessed by dtk from accesses and may be wrong.
- `jumptable_XXXXXXXX`: switch jump table.
- Real names exist only for library code dtk recognises by signature (RVL SDK OS/EXI/SI/DVD/GX/IPC/NAND/SC/ES, MetroTRK, MSL, PPCEABI runtime), e.g. `OSInit`, `memcpy`, `__init_cpp_exceptions`. 444 more functions are bounded by exception tables.

8283 functions total; 2941 lie in the game range 0x8000BF80..0x800EB1CC.

The IDA database (`game/base/mm9-game.dol.i64`) is plain auto-analysis: 7358 functions, one name (`start`), no types, no comments. It was used for xrefs and string references only, from a copy in `build/ida/` so the original stays untouched.

## Naming policy

Don't rename to semantic names without evidence (strings, SDK signatures, unambiguous use). Struct types and fields use `Unk<ADDR>` / `unkXX` until their purpose is pinned down. Shared partial structs live in `include/game/`:

- `obj.h`: pooled object from `fn_800E8C44(lbl_804EE738)`, initialised by `fn_80042DA0(obj, type)`.
- `stateobj.h`: object with `state` at 0x11 and `flags14` at 0x14 used by the per-type update/draw pairs.
- `work_802BDCC0.h`: the big work area at the start of `.bss`.
- `sound.h`: `enum SoundEffect`, the 95 sound effect ids `fn_800D5234` accepts, and `enum Music`, the 33 music ids for `fn_800D5564`/`fn_800D56A4`/`fn_800D57BC`. Call sites in `src/game/` use the names.
- `stage.h`: `enum Stage`, the 15 stage ids, named after the music `lbl_80272E44` assigns each one (Magma Man is 1, Hornet Man 2, ..., Wily 1-4 are 9-0x0C).

## Names from data files

`rockman9.brsar` (Wii WAD content 2; byte-identical to the XBLA copy) is the NW4R sound archive with its `SYMB` table intact: 228 sound labels.

- `fn_800D5234(id)` maps a game sound id through `lbl_80280440` (u16 archive index, channel mask, priority) to an archive sound; that label is the `SoundEffect` name. Sanity check: id 0x13 (`SE_EXPLOSION`) is played right after the explosion effect spawns.
- `lbl_802805C0` holds four archive sequence numbers per music id, the `_S1`/`_S2`/`_TR`/`_NO` variants of one `SEQ_` label; the `Music` name is that label.
- `lbl_80272E44[stage]` is the music `fn_80082950` starts for a stage, which is how stage ids get their names. The stage descriptors at 0x80275CF4 and on name `st00.bin`..`st0e.bin` in the same order.

## Other releases

- **XBLA** (`default.xex`, MSVC): stripped. No game symbols, no game RTTI (only `std::bad_alloc`/`std::exception`), only the PDB path `c:\DriveD\rockman9\prog\prog_360\bin\rm9.pdb`. It still carries the Wii save-error strings, so it was ported from the Wii source; useful as a semantic cross-reference, not for matching.
- **PS3** (`EBOOT.BIN`, decrypted `EBOOT.elf`): stripped too, no symbol table, no source paths.
- **Legacy Collection 2** (`MMLC2.exe`, MSVC x64, SteamStub-wrapped; unpacked with Steamless): the game functions are unnamed. Its RTTI only covers the collection's own C++ framework (`CMaingameMM09Task`, `CDebugMM09Task`, `CUOptionMM09`, `CUMuseumIllust_MM09`, menu/save/achievement classes); the PDB path is `C:\bullets\rcc2\PROG\pc_sys\output\bin\Releasex64\MMLC2.pdb` and the only source paths are framework files (`..\cross_sys\src\bullets_sys\Mem\COMemMng.cpp`, ...). MM9's tables (stage descriptors, `wsc_*.bin` names) are carried over, so it's a third compiled copy of the game logic for cross-reference.
